Free Server Limits

DataLens is hosted on a free server with limited resources. Please note:

  • File size limit: 5 MB
  • Row limit: 5,000 rows for best performance
  • First request may take 30-50 seconds (cold start)
  • 512 MB RAM — large datasets may crash
  • Data is lost if server restarts — download reports quickly
For best results, use CSV files under 2 MB with up to 2,000 rows.
